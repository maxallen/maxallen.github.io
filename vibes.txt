# File Structure
Here's the file structure we'll create:

```
index.html              // Homepage
about.html              // About Me page
blog.html               // Blog listing page
reading-list.html       // Reading list page
projects.html           // Projects page
css/
  ├─ styles.css         // Main stylesheet
  └─ blog-styles.css    // Blog-specific styles
js/
  ├─ main.js            // Main JavaScript file
  └─ blog.js            // Blog-specific JavaScript
assets/
  └─ images/            // Directory for images
blog/
  ├─ posts/             // Directory for markdown blog posts
  │  ├─ post1.md
  │  └─ post2.md
  └─ blog-post.html     // Template for blog posts
```
